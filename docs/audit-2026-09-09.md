# Repository audit — 2026-09-09

Reviewed the application and applied targeted fixes for reproduced security, migration, scheduling, export, and test-isolation defects. Final validation: **756 unit/integration tests and 132 browser tests passed**, production build passed, and `npm audit` reported **zero known vulnerabilities**. Remaining findings are listed below; passing tests do not certify the application free of defects.

Base revision: `6017e91`. Existing edits in `.claude/settings.local.json` and the user-provided `AGENTS.md` were preserved.

## Remaining findings and limitations

These are recorded follow-up items, not silently treated as fixed.

| Priority | Finding and evidence | Follow-up |
| --- | --- | --- |
| Medium | **Restore still validates structure and relationships more thoroughly than individual records.** A synthetic restore with malformed time markup returned 200 and preserved the value. Escaping fixes the demonstrated renderer execution path, but malformed dates/times/numeric fields can still produce unusable records. Optional non-array tables become empty arrays and invalid associations are dropped, as currently documented. | Define versioned per-record validation and a compatibility policy for historical backups before tightening restore. Validate the entire payload before replacement; test rejection without data loss. |
| Medium | **Subdirectory support is incomplete.** `Layout.jsx` uses `window.location.pathname` for sidebar cycling and cross-view source detection, while router paths omit the configured basename. With `/curriculum/`, those comparisons do not match `/` or `/monthly`. This is a source-confirmed issue; the browser suite ran at `/`. | Use router-relative location consistently and add a deployment test under a non-root BASE, including proxy/API/static routing. |
| Medium | **Keyboard and assistive-technology coverage has gaps.** Multiple forms use visual labels without input associations; schedule blocks are clickable divs; the closed mobile drawer is translated offscreen without being inert. The focus-trap selector also includes disabled/hidden controls. | Associate labels, define keyboard interaction for schedule cells/blocks, remove closed drawer controls from the focus order, and test enabled/visible focus boundaries with browser and screen-reader checks. |
| Medium | **Generated systemd service has no `User=` and Chromium disables its sandbox.** Installing the supplied system service as documented therefore runs it as root unless the operator modifies it. This increases the impact of future renderer/server vulnerabilities. No host compromise was attempted or demonstrated. | Provide a dedicated service account with explicit data/cache permissions and verify a supported Chromium sandbox setup on the target host. |
| Low | **Scalar API field shapes remain permissive outside auth.** Actual requests with `studentCount: [2]`, `unitPrice: [100]`, or `grade: ["高一"]` returned 200. This is coercion inconsistent with the documented scalar contract; the probes did not demonstrate an authorization bypass. | Decide whether numeric-string compatibility is intentional, then consistently reject arrays/objects while preserving approved scalar forms. |
| Low | **Dense weekly PNG blocks can hide class names.** Visual inspection of two overlapping classes showed a one-hour narrow block displaying its time while the name was fully clipped. PNG generation succeeds, but the output loses identifying text. | Give the class name space priority or use a compact stacked layout, then visually test narrow conflict columns. |

Operational boundaries retained: historical passwords longer than 72 bytes cannot be repaired from their hashes; users with such passwords should reset them. Report and semester caches are process-local, so independently running server processes or direct database edits do not share invalidations. Snapshot retention is a five-file directory-wide policy, not a per-teacher recovery guarantee. Audit logging is best-effort and its batch records are not a complete undo journal. Semester boundary and pricing-history behavior were left consistent with the existing documented/tested policy.

## Test-isolation incident

The initial existing test run created pre-restore snapshots in the real `data/` directory because `route-helpers.js` exported that directory. Its cleanup routine can prune older matching snapshots. Service imports also opened the default SQLite database. No pre-run snapshot inventory was captured, so **loss of older snapshots cannot be ruled out**. This audit did not attempt to reconstruct or delete those files, and it did not deliberately issue application-record mutations against the real database.

After isolating both paths, the complete final unit/browser runs and image smoke checks left every application data-directory file's size and modification timestamp unchanged. This verifies the corrected runs; it does not establish what existed before the initial run.
