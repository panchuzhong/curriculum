# Repository audit — 2026-09-14

Full-codebase review on top of the pending 排课历史 feature (班级详情第三个标签页). Four parallel read-only audit passes covered server routes/auth, services + DB, the React client, and tests/tooling/docs, plus a diff review of the uncommitted feature. All reproduced findings were fixed with regression tests; the rest are recorded below. Final validation: **771 unit/integration tests and 140 browser tests passed**, production build, `npm audit` (0 vulnerabilities), and shell syntax checks all passed.

Base revision: `7e2cc5b` plus the then-uncommitted 排课历史 changes (now part of this release). Known findings carried over from [audit-2026-09-09](./audit-2026-09-09.md) were excluded from re-reporting.

## Fixed findings

Severity reflects demonstrated effect and required access, not CVSS.

| Priority | Finding and failure scenario | Fix and evidence |
| --- | --- | --- |
| Medium | **Registration reopened after every restart when `ALLOW_REGISTRATION` came from the process environment** (systemd `Environment=`, `docker -e`, the README's own `ALLOW_REGISTRATION=true node …` style). dotenv does not override an already-set variable, so the `.env` rewrite was inert and the single-user invariant silently degraded to a username-uniqueness check. | The occupied `teachers` table is now the invariant inside the synchronous claim section. `server/routes/auth.js`; restart-style reset regression in `routes-auth.test.js`. |
| Medium | **Migration `try { ALTER } catch {}` recorded non-duplicate-column failures as applied.** A busy lock or full disk during v1/v2 left `subjects`/student columns missing forever with no repair path (only v3/v4 had one). | `addColumn` rethrows everything except duplicate-column; v1/v2 ledger repair added beside the v3/v4 ones. `server/db/index.js`; column-drop repair test in `db-migration-legacy.test.js`. |
| Medium | **The semester cache never expired.** Unlike the report cache (60s TTL), `getTeacherSemesters` cached per teacher forever with only same-process invalidation — a semester edited by another process sharing the SQLite file was never seen, silently corrupting batch-scheduling semester guards. | 60s TTL mirroring the report cache. `server/services/schedule-helpers.js`; fake-timer regression in `schedule-helpers.test.js`. |
| Medium | **排课历史 discarded fetched schedules when the semesters fetch failed.** `Promise.all` rejected, the catch set `all=[]`, and the tab showed a convincing「该时段无排课」for a class with lessons. | The semesters request now degrades to「default range = all lessons」with a toast; schedules render regardless. `src/classes/ScheduleHistory.jsx`; route-interception browser regression in `tests/classes.spec.ts`. |
| Medium ×6 | **Vacuous E2E tests.** 报表卡片数字测试断言的是周区间标签（恒真）；切班级筛选测试无数据断言；手动添加节假日整段条件包裹且从未点到按钮（添加区是 div 不是 form），且会泄漏数据；按班级筛选学生/点击编辑按钮两个纯动作测试；月视图点击与年视图统计两个空测试；周导航 `>=0` 恒真。 | All rewritten with real oracles (URL jumps, table-row appearance/disappearance, summary counts) and self-cleanup; fixed sleeps replaced with polled assertions. `tests/*.spec.ts`. |
| Low | `PUT /api/auth/subjects` was mounted before the global `/api` write limiter and carried none of its own. | `authLimiter` added. `server/routes/auth.js`. |
| Low | `POST /api/backup/restore/` (trailing slash; strict routing off) hit the global 1MB parser and 413'd before the route's 50MB parser. | Path-normalized exemption. `server/index.js`; regression in `app-integration.test.js`. |
| Low | The pricing "keep at least one record" count check ran outside the transaction; two concurrent deletes could empty a class's pricing history (cross-process). | Check moved inside the transaction, mapped to the same 400. `server/routes/classes.js`. |
| Low | Migration v3's backfill derived `effective_from` from a legacy `created_at` holding the literal `CURRENT_TIMESTAMP`, producing `'CURRENT_TI'` — a value that sorts after every ISO date, so the initial pricing record never matched any lesson. | The created_at repair now runs before the migration loop. `server/db/index.js`; legacy-DB regression in `db-migration-legacy.test.js`. |
| Low | Remaining prototype-chain lookups: `GRADE_LIGHTNESS[grade]`, `HOLIDAYS[year]`, `WORKDAYS[year]`, `HOLIDAY_NAMES[mmDd]` returned inherited members for hostile keys (`"constructor"`), poisoning color math or throwing on `.includes`. | Own-property guards everywhere (`Object.hasOwn`), completing the 2026-09-09 fix that only covered `SUBJECT_HUES`. `server/services/colors.js`, `holidays.js`. |
| Low | `buildPricingLookup` sorted by `localeCompare` but matched by code-unit `<=`; the orderings can disagree for non-ISO `effective_from` values (restore path), breaking the scan early. | Single code-unit comparator. `server/services/schedule-helpers.js`. |
| Low | `seedPricingTiers` inserted five rows non-atomically; a partial default set would never be repaired (the guard sees >0 rows). | Wrapped in one transaction. `server/db/seed.js`. |

## Remaining findings and limitations

Recorded follow-ups, not silently treated as fixed. Carried-over items from the 2026-09-09 audit (restore per-record validation, BASE_URL subdirectory support, accessibility gaps, generated systemd service hardening, dense-PNG name clipping, permissive scalar coercion) remain open.

| Priority | Finding and evidence | Follow-up |
| --- | --- | --- |
| Medium | **API keys are stored in plaintext** (`teachers.api_key`); database-file access grants full account access. Rotation changes the value, not the scheme. | Store a keyed hash, compare by lookup; requires a migration and Settings/API-key UX changes. |
| Low | Foreign-resource failures return 403 in schedules routes but 404 in classes/students/holidays/pricing-tiers/semesters. | Pick one convention (404 hides existence and matches the majority) and align. |
| Low | `PUT /api/classes/:id` accepts `unitPrice`/`studentCount`/`discountAmount` and persists them to `classes`, but revenue prefers `classPricing`, so API consumers editing price this way see no revenue change. The shipped UI edits via `/pricing`. | Either create a pricing version on price-field changes or reject those fields on the class PUT. |
| Low | `/summary`, `/export`, `/conflicts` accept unbounded date ranges (GET `/` caps at 365 days without a filter). Teacher-scoped, so a consistency/performance gap rather than a leak. | Decide a cap (or the same classId escape) consistent with GET `/`. |
| Low | Login timing distinguishes existing vs non-existing usernames (bcrypt only runs for the former); registration is closed and login is rate-limited 10/15min. | Dummy compare for unknown usernames if deemed worth closing. |
| Low | Batch holiday import permits a missing/empty `name` while single create requires one. | Align the validators (likely: allow empty with the generic fallback everywhere). |
| Low | PricingManager labels the latest record 「当前定价」 even when `effectiveFrom` is in the future; the ClassList header then shows future pricing while report revenue stays date-effective. | Either gate「当前」on `effectiveFrom <= today` or annotate the header. |
| Low | Relative-date E2E seeds (delete-preview, month-filter fixtures) accumulate in the persistent `data/e2e.db`; oracles recompute so correctness holds, but the file grows across runs. | Periodic reset or seed-row cleanup. |
| Low | Date helpers are re-implemented locally in several specs instead of importing from `tests/auth.ts`. | Consolidate on the shared helpers. |
